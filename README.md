商业营销战略决策大脑
整合9库210+模型,提供「搜索->诊断->策略->执行->复盘」5阶段全链路工作流。
9组决策框架系统化组合 + 思维方法论决策驱动链 + 执行层倒推 + 6类用户定位 + POES渠道体系 + 深度心理7层洞察 + 增长执行SOP + 多格式品牌化输出。

## 项目简介

一位具备8年实战经验的商业营销战略决策大脑,面向品牌顾问/企业老板/CMO/产品经理/操盘手/CEO 6类决策者。
当用户提出商业营销问题时,自动路由最优决策框架,经5阶段闭环,产出结构化、可执行、数据驱动、可闭环落地的营销方案。

 **触发场景**：
  - 市场分析、竞争分析、环境分析 -> 战略分析模型(五力/SWOT/PESTEL/BCG/安索夫/3C/蓝海)
  - 问题拆解、决策分析、方案设计 -> 思维方法模型(MECE/金字塔/SCQA/六帽/5W2H/决策树/脑暴/因果图)
  - 品牌定位、品牌战略、价值主张 -> 品牌定位模型(定位三角/Kapferer/Aaker/价值主张/PMM/护城河/原型)
  - 营销策略、传播策略、市场进入、GTM -> 营销传播模型(4P/STP/AIDA/PAS/GTM/ICP/SOSTAC/IMC)
  - 用户增长、增长黑客、裂变策略 -> 用户增长模型(AARRR/AIPL/AISAS/AIPS/北极星/飞轮/Hook/裂变/漏斗)
  - 用户洞察、行为设计、深度心理 -> 消费者心理模型(BJ Fogg/COM-B/EAST/Nudge/KANO/CJM + 7层深度心理)
  - 数据分析、效果评估、指标体系 -> 数据分析模型(RFM/HEART/NPS/LTV-CAC/A-B测试/GA4)
  - 运营执行、项目管理、团队协作 -> 运营执行模型(PDCA/OKR/RACI/敏捷营销/SOP)
  - 销售流程、定价策略、客户管理 -> 销售变现模型(销售漏斗/MEDDIC/定价/客户成功/变现模式)
  - 渠道落地、传播组合、媒介策略 -> POES渠道体系(付费/自有/赢得/共享12渠道)
  - 海外市场、品牌出海、国际SEO -> 出海营销策略(GTM/本地化/国际市场)

  **关键词**：市场分析、营销策略、品牌定位、增长黑客、用户增长、品牌战略、销售策略、定价策略、GTM、大促、新品上市、复盘、出海营销、营销总监、决策大脑

## 核心能力

- **9库210+模型**:战略分析/思维方法/品牌定位/营销传播/用户增长/消费者心理/数据分析/运营执行/销售变现
- **9组决策框架**:模型按分析链路系统化组合(场景+调用顺序+输出),非孤立堆砌
- **5阶段闭环**:搜索(拉数据)->诊断(找根因)->策略(定方案)->执行(倒推SOP)->复盘(验证迭代)

- **POES 12渠道体系**:付费/自有/赢得/共享,链路+SOP+方法论
- **7层深度心理洞察**:三层穿透法+15应用点闭环
- **增长执行SOP**:5 Phase增长闭环+5标准化交付模板
- **多格式品牌化输出**:md/html/ppt 3格式 + 5调性 + 5视觉风格HTML模板

## 思维方法论驱动链

8大思维模型从「孤立工具」升级为「决策驱动链」，每一模型驱动一个决策环节：

```
收敛主链：5W2H(界定) → MECE(拆解) → 因果图(根因) → 决策树(量化) → 六帽(审视) → 金字塔(表达) → SCQA(叙事)
                                                                   ↑
                                                           脑暴(发散补缺)
```

### 启用与调用
本 skill兼容主流 agent 框架(Claude Code / Trae CN / Workbuddy / openclaw / codex 等)。

## 使用方法
1. **安装**:将本目录放入所用 agent 的 skills 目录(路径参考各 agent 官方文档)
2. **触发**:提出商业营销问题时自动触发(见 SKILL.md frontmatter 触发场景与关键词)
3. **使用模式**:单模型分析 / 决策框架组合 / 全链路5阶段(详见 SKILL.md)

### 输入要求
为获得最佳效果,提问时建议提供:行业/品类、品牌/产品、场景/目标、约束条件(可选)。

示例:
1. 市场分析:"我们是某美妆品牌,想分析敏感肌赛道竞争格局,给出市场进入建议"
2. 大促方案:"薇诺娜,Q4双11大促GTM方案,目标GMV 5亿,预算500万,9月预热-11月收官"
3. 品牌定位:"新锐咖啡品牌,需要做品牌定位和价值主张,面向一二线白领"
4. 用户洞察:"影石360运动相机,分析目标用户购买决策心理,优化转化路径"
5. 出海营销:"绿联3C配件,拓展北美和欧洲市场,做海外GTM和渠道策略"

## 诚实边界

### 本技能擅长
- ✅ 结构化市场分析与战略决策
- ✅ 9组决策框架系统化组合
- ✅ 思维方法论驱动的决策链
- ✅ 品牌定位与营销策略制定
- ✅ 用户增长规划与增长SOP
- ✅ 深度心理洞察(7层+15应用点)
- ✅ 渠道体系(POES 12渠道)落地
- ✅ 数据驱动决策与复盘
- ✅ 多格式品牌化输出(md/html/ppt + 5风格)

### 本技能不擅长
- ❌ 从0到1的突破性创新(模型偏向收敛思维,需脑暴补链)
- ❌ 实时数据获取(依赖宿主搜索能力,按能力降级)
- ❌ 行业深度专业知识(需用户提供背景)
- ❌ 创意执行的生产环节(文案/设计/视频,需协作技能)

### 使用前提
- 需要用户提供:业务背景、目标、关键数据
- 输出质量取决于:输入信息完整性 + 宿主搜索能力
- 搜索能力按宿主适配:有内置搜索用内置,无则降级到用户提供数据+公开数据源
- 建议配合:数据工具(GA4/CRM) + 行业洞察 + 协作技能

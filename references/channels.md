# 渠道落地(12渠道 POES体系)

> strategic-marketing-director v2.0.0 references
> 营销传播渠道层:POES分类,12渠道每个定义用户链路 + 运营工作流 + SOP + 驱动方法论

## 渠道体系(POES 模型)
- **P 付费媒体(Paid)**:花钱买曝光/流量 -- SEM/信息流/KOL/OOH·TV
- **O 自有媒体(Owned)**:自己控制的阵地 -- SEO/官网App/私域/EDM
- **E 赢得媒体(Earned)**:用户/媒体自发传播 -- PR/UGC口碑
- **S 共享媒体(Shared)**:社媒互动分享 -- 社媒内容/社区

---

## 一、付费媒体(Paid)

### 1. 搜索广告(SEM)
- **用户链路**:搜索关键词 -> 看广告 -> 点击 -> 落地页 -> 转化
- **工作流**:关键词调研 -> 账户搭建 -> 创意撰写 -> 出价 -> 投放 -> 优化
- **SOP**:SEM投放SOP -- 关键词挖掘(意图分层)-> 分组 -> 创意A/B -> 出价策略 -> 质量度优化 -> 转化追踪 -> 复盘
- **方法论**:搜索意图匹配、质量度优化、A/B测试、LTV-CAC

### 2. 信息流/展示广告
- **用户链路**:浏览内容 -> 信息流曝光 -> 点击 -> 落地页 -> 转化
- **工作流**:人群定向 -> 素材制作 -> 投放 -> 频次控制 -> 优化
- **SOP**:信息流投放SOP -- 人群包 -> 素材矩阵 -> 出价 -> 频次控制 -> CTR/CVR优化 -> 复盘
- **方法论**:受众定向、素材测试、频次控制、A/B测试

### 3. KOL/达人投放
- **用户链路**:达人内容曝光 -> 粉丝关注 -> 信任传递 -> 转化
- **工作流**:达人筛选 -> 合作Brief -> 内容共创 -> 投放 -> 效果评估
- **SOP**:KOL投放SOP -- 筛选(量级/调性/数据)-> Brief -> 共创 -> 投放 -> ROI评估 -> 复投决策
- **方法论**:达人分层、信任传递、CPE/ROI、社交认同

### 4. 户外/电视/广播(OOH/TV)
- **用户链路**:场景曝光 -> 品牌记忆 -> 线上搜索/到店
- **工作流**:点位/时段选择 -> 创意 -> 投放 -> 效果评估
- **SOP**:传统媒介SOP -- 受众匹配 -> 点位/时段 -> 创意 -> 投放 -> 品牌提升评估
- **方法论**:频次到达、品牌曝光、AIDA注意层

## 二、自有媒体(Owned)

### 5. SEO(自然搜索)
- **用户链路**:搜索需求 -> 自然结果 -> 点击 -> 内容 -> 转化
- **工作流**:关键词策略 -> 内容生产 -> 技术SEO -> 外链 -> 排名监测
- **SOP**:SEO优化SOP -- 关键词挖掘 -> 内容矩阵 -> 技术优化(速度/结构/移动)-> 内链外链 -> 排名监测 -> 迭代
- **方法论**:搜索意图、内容质量、技术SEO、长期复利

### 6. 官网/App/小程序
- **用户链路**:访问 -> 浏览 -> 互动 -> 转化 -> 留存
- **工作流**:用户体验 -> 内容更新 -> 转化优化 -> 留存运营
- **SOP**:自有阵地SOP -- 访问分析 -> 体验优化 -> 转化CRO -> 留存推送 -> 迭代
- **方法论**:CJM、CRO转化率优化、HEART、BJFogg

### 7. 私域(社群/企微/公众号)
- **用户链路**:引流 -> 进群/关注 -> 互动 -> 培育 -> 转化/复购
- **工作流**:引流 -> 分层 -> 内容培育 -> 活动转化 -> 复购
- **SOP**:私域运营SOP -- 引流钩子 -> 分层标签 -> 内容SOP(日/周节奏)-> 活动转化 -> 复购激励 -> 流失唤醒
- **方法论**:RFM分层、用户培育、Hook留存、Nudge助推

### 8. 邮件/短信(EDM/SMS)
- **用户链路**:触达 -> 打开 -> 点击 -> 转化
- **工作流**:名单管理 -> 内容 -> 触发 -> 优化
- **SOP**:EDM/SMS SOP -- 名单分层 -> 内容个性化 -> 触发时机 -> A/B测试 -> 效果追踪
- **方法论**:生命周期触发、个性化、A/B测试

## 三、赢得媒体(Earned)

### 9. PR公关
- **用户链路**:媒体报道 -> 用户信任 -> 搜索/到店
- **工作流**:选题 -> 媒体关系 -> 稿件 -> 发布 -> 监测
- **SOP**:PR公关SOP -- 选题策划 -> 媒体清单 -> 稿件 -> 发布 -> 舆情监测 -> 危机预案
- **方法论**:议程设置、信任背书、危机管理

### 10. 口碑/UGC/病毒传播
- **用户链路**:用户体验 -> 自发分享 -> 传播 -> 新用户
- **工作流**:超预期体验 -> 激励分享 -> 传播放大
- **SOP**:口碑/UGC SOP -- 体验设计 -> 分享激励 -> UGC收集 -> 传播放大 -> K系数追踪
- **方法论**:裂变(K=happy×spread)、社交货币、口碑飞轮

## 四、共享媒体(Shared)

### 11. 社媒内容(小红书/抖音/微博/微信/知乎类平台)
- **用户链路**:内容曝光 -> 互动(赞评藏转)-> 关注 -> 转化
- **工作流**:平台选择 -> 内容生产 -> 发布节奏 -> 互动 -> 数据
- **SOP**:社媒运营SOP -- 平台矩阵 -> 内容选题(爆款公式)-> 发布节奏 -> 互动维护 -> 数据复盘 -> 迭代
- **方法论**:平台算法、内容钩子、AISAS、社交认同、内容飞轮

### 12. 社区/论坛
- **用户链路**:社区互动 -> 信任 -> 转化
- **工作流**:社区定位 -> 内容 -> 互动 -> 转化
- **SOP**:社区运营SOP -- 定位 -> 内容 -> KOC培育 -> 活动 -> 转化
- **方法论**:社区飞轮、KOC、信任建设

---

## 渠道协同方法论(IMC整合)
- **POES协同链路**:Paid引流 -> Owned承接 -> Earned放大 -> Shared裂变
- **IMC整合传播**:多触点一致信息,覆盖用户旅程(AIDA/AISAS)
- **渠道组合原则**:按目标(品牌/效果)选渠道组合,按预算(LTV-CAC)分配

## 渠道路由表

| 营销目标 | 主渠道 | 协同渠道 | 方法论 |
|---|---|---|---|
| 品牌曝光 | OOH/TV + 社媒 | PR + SEO | AIDA注意 + 频次到达 |
| 效果转化 | SEM + 信息流 | 私域 + EDM | 漏斗 + CRO + LTV-CAC |
| 用户增长 | 社媒 + 裂变 | KOL + SEO | AARRR + 裂变K |
| 口碑建设 | PR + UGC | 社媒 + 社区 | 信任 + 社交货币 |
| 私域复购 | 私域 + EDM | 社媒 | RFM + Hook + Nudge |

**关键原则**:渠道名作平台类型示例,不绑定具体产品。POES分类 + IMC协同 是渠道组合的方法论骨架。

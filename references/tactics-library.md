# 9组执行层(战术 + 工具 + SOP)

> strategic-marketing-director v2.0.0 references
> 9组决策框架(战略层:怎么想)对应9组执行层(战术层:怎么做),打通"策略方案 -> 可执行动作"

## 倒推逻辑
```
决策框架(战略层:用什么模型分析出方案)
       ↓ 倒推
执行层(战术:做什么 + 工具:用什么 + SOP:按什么流程)
       ↓
执行路线图(可落地行动计划)
```

---

## 执行层1:战略落地(对应框架1 战略分析)
- **战术**:市场进入决策(进/不进/怎么进)、业务组合调整(投/撤/持)、增长方向选择(安索夫4象限:渗透/开发/延伸/多元化)
- **工具**:BCG 矩阵表、安索夫矩阵、战略地图(方法论工具)
- **SOP**:战略复盘SOP -- 环境再扫描 -> 定位校验 -> 方向调整 -> 资源再分配 -> 战略地图更新(年度/季度)

## 执行层2:决策落地(对应框架2 思维决策)
- **战术**:问题解决方案执行、决策传达与对齐
- **工具**:决策记录文档、金字塔汇报模板、RACI 责任矩阵
- **SOP**:决策落地SOP -- 决策记录(结论+依据) -> RACI 分配 -> 执行跟踪 -> 阶段复盘 -> 归档

## 执行层3:品牌建设(对应框架3 品牌定位)
- **战术**:品牌识别系统建设(VI 视觉/MI 理念/BI 行为)、品牌内容矩阵、品牌触点管理
- **工具**:品牌手册、Kapferer 品牌棱镜表、Aaker 资产模型表(方法论工具)
- **SOP**:品牌建设SOP -- 定位确认 -> 识别系统搭建 -> 内容矩阵规划 -> 触点落地 -> 品牌资产监测

## 执行层4:营销传播落地(对应框架4 营销传播)
- **战术**:GTM 上市推进、营销战役执行、整合传播投放(多触点一致)
- **工具**:GTM checklist、4P 执行表、IMC 传播日历、AIDA 转化漏斗监测看板(通用BI)
- **SOP**:上市/战役SOP -- 预热(造势) -> 上线(首发) -> 放量(扩渠道) -> 收尾(转化) -> 复盘(ROI)
- **渠道落地**:见 `references/channels.md`(12渠道垂直SOP)

## 执行层5:增长运营(对应框架5 用户增长)
- **战术**:AARRR 各环节优化(获客/激活/留存/变现/裂变)、增长实验
- **工具**:增长漏斗看板、AARRR 指标表、北极星追踪表、飞轮图(通用BI/增长平台)
- **SOP**:增长实验SOP -- 假设 -> 实验 -> 测试 -> 数据 -> 复盘 -> 规模化/废弃
- **增长执行全流程**:见 `references/growth-execution.md`(5 Phase增长SOP)

## 执行层6:转化优化(对应框架6 消费者心理)
- **战术**:转化路径优化、触点助推设计、行为引导机制(默认/社会证明/稀缺)
- **工具**:CJM 地图、BJFogg 行为设计表、Nudge 清单、A-B 测试平台(通用)
- **SOP**:转化优化SOP -- 旅程测绘 -> 痛点定位 -> 助推设计 -> A-B 测试 -> 上线放量
- **深度心理**:见 `references/psychology-deep.md`(7层模型 + 15应用点闭环)

## 执行层7:数据驱动(对应框架7 数据分析)
- **战术**:指标体系搭建、用户分层运营(RFM)、实验验证迭代
- **工具**:指标字典、RFM 分层表、HEART 评估表、A-B 测试平台、数据采集看板(通用BI/GA4类)
- **SOP**:数据驱动SOP -- 指标定义 -> 数据采集 -> 分层分析 -> 实验验证 -> 决策迭代

## 执行层8:运营管控(对应框架8 运营执行)
- **战术**:OKR 对齐、项目推进、流程标准化
- **工具**:OKR 表、RACI 矩阵、SOP 文档库、项目三角平衡表、营销日历(通用项目管理)
- **SOP**:运营管控SOP(PDCA闭环) -- 目标对齐(OKR) -> 责任分配(RACI) -> 执行 -> 检查 -> 改进

## 执行层9:销售变现(对应框架9 销售变现)
- **战术**:销售流程执行、定价落地、客户全生命周期管理
- **工具**:销售漏斗 CRM、MEDDIC 判定表、定价表、客户成功 Onboarding 清单(通用CRM)
- **SOP**:销售执行SOP -- 线索 -> 商機(MEDDIC判定) -> 成交 -> Onboarding -> Expansion(增购/续费)

---

## 执行层闭环(衔接5阶段)
```
策略阶段产出:策略方案
       ↓
执行层(本文件):战术 + 工具 + SOP(把方案拆为可执行动作)
       ↓
执行阶段产出:执行路线图(OKR + RACI + SOP + 日历)
       ↓
复盘阶段:验证执行效果
```

**关键原则**:9组框架解决"怎么想",9组执行层解决"怎么做"。SOP 是标准化可重复流程,把战略方案转为可落地动作链。工具用通用类别(方法论工具/BI/CRM/测试平台),不绑定具体产品,适配所有用户环境。

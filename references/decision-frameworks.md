# 9组决策框架

> strategic-marketing-director v2.0.0 references
> 66模型系统化组合:9库对应9场景,每场景定义模型组合 + 调用顺序 + 输出

## 设计原则
每库对应一场景,组内定义:场景边界 + 模型组合 + 调用顺序 + 输出。模型按"分析链路"组合(环境扫描 -> 定位 -> 组合 -> 综合),非堆砌。

---

## 框架1:战略分析场景(战略库 7模型)
**场景**:评估行业吸引力 / 竞争地位 / 市场进入 / 战略方向选择
**调用顺序**:
```
环境扫描: PESTEL(宏观) + 五力(行业)
    ↓
竞争定位: 3C(自身-对手-客户)
    ↓
业务组合: BCG矩阵 + 安索夫(增长方向)
    ↓
综合判断: SWOT(收口) + 蓝海(创新方向)
```
**输出**:战略定位报告(行业吸引力评分 + 竞争地位判断 + 战略方向建议)

## 框架2:思维决策场景(思维库 8模型)
**场景**:复杂问题拆解 / 决策分析 / 方案结构化 / 团队多维决策
**调用顺序**:
```
界定: 5W2H(问题边界)
    ↓
拆解: MECE + 因果图(根因)
    ↓
决策: 决策树(量化) + 六帽(多维审视)
    ↓
表达: 金字塔 + SCQA + 脑暴(发散补缺)
```
**输出**:结构化决策报告(问题定义 + 拆解树 + 量化决策 + 方案叙事)

## 框架3:品牌定位场景(品牌库 7模型)
**场景**:新品牌定位 / 品牌重塑 / 品牌架构 / 价值主张设计
**调用顺序**:
```
核心: 价值主张(承诺) + 定位三角(差异点)
    ↓
体系: Kapferer(六维) + Aaker(资产)
    ↓
匹配防御: PMM + 护城河 + 原型(人格)
```
**输出**:品牌定位方案(价值主张 + 差异点 + 品牌体系 + 防御壁垒)

## 框架4:营销传播场景(营销传播库 8模型)
**场景**:新产品上市 / 营销战役 / 传播策略 / 市场进入GTM
**调用顺序**:
```
目标锁定: STP + ICP(理想客户)
    ↓
营销组合: 4P + GTM(上市路线)
    ↓
传播链路: AIDA + PAS + SOSTAC-RACE + IMC(整合)
```
**输出**:营销传播方案(STP + 4P + GTM路线 + 传播链路)

## 框架5:用户增长场景(增长库 9模型)
**场景**:用户增长 / 拉新留存 / 裂变 / 增长体系搭建
**调用顺序**:
```
方向: 北极星指标 + 飞轮(增长引擎)
    ↓
漏斗: AARRR + 漏斗(转化诊断)
    ↓
旅程: AIPL/AISAS/AIPS + Hook(留存) + 裂变(K系数)
```
**输出**:增长方案(北极星 + 飞轮 + AARRR漏斗 + 旅程优化 + 裂变设计)

## 框架6:消费者心理场景(心理库 7模型)
**场景**:用户行为设计 / 转化提升 / 体验优化 / 用户洞察
**调用顺序**:
```
理解: CJM(旅程) + KANO(需求优先级)
    ↓
设计: BJFogg(B=MAT) + COM-B(行为改变)
    ↓
助推: EAST + Nudge + 70+心理速查
```
**输出**:行为设计方案(旅程痛点 + 行为模型 + 助推策略 + 心理触发点)
**深度心理**:见 `references/psychology-deep.md`(7层深度模型 + 15应用点闭环)

## 框架7:数据分析场景(数据库 6模型)
**场景**:数据驱动决策 / 指标体系 / 效果评估 / 用户分层
**调用顺序**:
```
经济与分层: LTV-CAC(单位经济) + RFM(分层)
    ↓
体验与忠诚: HEART + NPS
    ↓
实验验证: A-B测试 + GA4(归因)
```
**输出**:数据分析报告(单位经济 + 用户分层 + 体验评估 + 实验结论)

## 框架8:运营执行场景(运营库 7模型)
**场景**:项目落地 / 团队协作 / SOP制定 / 计划执行管控
**调用顺序**:
```
目标: OKR + PDCA
    ↓
协作: RACI + 敏捷
    ↓
标准: SOP + 项目三角 + 营销日历
```
**输出**:执行计划(OKR + RACI责任矩阵 + SOP + 节奏日历)

## 框架9:销售变现场景(销售库 7模型)
**场景**:销售流程设计 / 定价 / 客户管理 / 变现模式
**调用顺序**:
```
转化与流程: 销售漏斗 + MEDDIC(2B销售)
    ↓
定价与变现: 定价策略 + 变现模式
    ↓
客户留存: 客户成功 + 2B销售 + 销售赋能
```
**输出**:销售变现方案(转化漏斗 + 销售流程 + 定价 + 客户留存体系)

# 输出交付(多格式 + 品牌调性 + 12视觉风格)

> strategic-marketing-director v2.0.0 references
> 输出从"文本报告"升级为"多格式品牌化交付":格式适配场景 + 调性适配品牌 + 风格适配视觉

---

## 一、交付格式(3种)

### 1. md交付(结构化文档)
- **场景**:方案文档 / 分析报告 / 知识沉淀
- **模板**:核心结论 + 分析过程 + 行动建议表(P0/P1)+ 风险预案
- **特点**:结构化、可版本控制、易编辑
- **调性应用**:文案语气按调性调整

### 2. html交付(可视化交互)
- **场景**:数据可视化 / 交互报告 / 在线分享
- **模板**:HTML报告(图表/流程图/交互组件/响应式)
- **特点**:可视化、交互、跨平台
- **工具**:通用 HTML/CSS/JS(不绑定具体框架)
- **调性应用**:色彩/字体/版式按风格呈现

### 3. ppt交付(汇报演示)
- **场景**:向上汇报 / 客户提案 / 团队对齐
- **模板**:演示deck(标题页 + 目录 + 内容页 + 总结页)
- **特点**:演示、视觉化、说服力
- **工具**:HTML PPT(html-ppt / frontend-slides 类通用skill生成)
- **调性应用**:视觉风格按风格设计

---

## 二、品牌调性(5种,管文案语气+色彩倾向,适配 md)

| 调性 | 色彩倾向 | 文案语气 |
|---|---|---|
| 高端 | 深色/金/黑 | 克制/意境 |
| 亲和 | 暖色/橙/粉 | 口语/陪伴 |
| 科技 | 冷色/蓝/银 | 专业/数据 |
| 活力 | 对比/亮色 | 激励/号召 |
| 专业 | 中性/灰/蓝 | 严谨/结构 |

## 三、视觉设计风格(12种,管 UI+动态+交互+效果,适配 html/ppt)

### 1. 现代主义(包豪斯)
- 视觉:网格系统、功能至上、无衬线、原色(红黄蓝)+黑白、几何
- UI:严格网格对齐、功能性组件、无装饰
- 动态:精准克制、线性过渡、无多余动效
- 实现:CSS Grid + 无衬线字体 + 原色调

### 2. 极简主义
- 视觉:大量留白、少元素、低饱和、细无衬线
- UI:极少组件、大留白、内容聚焦
- 动态:缓慢优雅、淡入淡出、呼吸感
- 实现:大留白 + 细字体 + 低饱和

### 3. 新野兽派
- 视觉:粗边框、高对比、平涂色块、无阴影无圆角、原始
- UI:粗边框组件、平涂按钮、border-radius:0
- 动态:直接硬切、无缓动、无过渡
- 实现:粗 border + 高对比色 + border-radius:0

### 4. 像素风
- 视觉:8-bit/16-bit、方块化、像素字体、拒绝抗锯齿、鲜艳
- UI:像素化组件、方块按钮、像素图标
- 动态:步进跳帧、像素抖动、游戏化
- 实现:像素字体 + image-rendering:pixelated + 鲜艳色

### 5. 极繁主义
- 视觉:视觉过载、混合图案/色彩/动效、满版、丰富
- UI:多层组件、丰富装饰、满版布局
- 动态:多动效叠加、多元素联动
- 实现:多层布局 + 混合图案 + 丰富动效

### 6. 复古风(70s/80s)
- 视觉:暖色调(橙/棕/黄)、印刷质感、复古字体、做旧
- UI:做旧组件、复古边框、暖色
- 动态:缓慢怀旧、做旧滤镜
- 实现:暖色 + 做旧纹理 + 复古字体

### 7. 玻璃拟物风
- 视觉:毛玻璃、半透明、折射光、模糊、通透
- UI:毛玻璃组件、半透明卡片、模糊层
- 动态:通透层次、模糊变化、光折射
- 实现:backdrop-filter:blur + 半透明 + 渐变

### 8. 终端风
- 视觉:纯黑背景、绿色代码、等宽字体、命令行
- UI:终端组件、命令行界面、等宽
- 动态:打字机、光标闪烁、命令输入
- 实现:黑底绿字 + 等宽字体 + 终端窗口

### 9. 北欧风
- 视觉:温暖、自然、柔和、木色/白/灰、圆润
- UI:圆润组件、柔和色、自然材质感
- 动态:温和自然、柔和过渡
- 实现:柔和色 + 圆润 + 木色

### 10. 后现代主义
- 视觉:矛盾、反叛、解构、打破规则、玩世不恭
- UI:错位组件、不对称、矛盾排版
- 动态:错位意外、反常规
- 实现:不对称 + 错位 + 矛盾色

### 11. 未来主义(赛博朋克)
- 视觉:高科技面板、HUD、霓虹色、冷峻科幻
- UI:HUD组件、科技面板、霓虹边框
- 动态:霓虹闪烁、数据流、HUD动效
- 实现:霓虹色 + HUD元素 + 科技字体

### 12. Y2K千禧
- 视觉:液态金属、气泡、全息、乐观科技感、鲜艳
- UI:液态组件、气泡卡片、全息质感
- 动态:液态流动、气泡、全息动效
- 实现:液态渐变 + 气泡 + 全息色

## 四、调性-风格映射(5调性 × 12风格)

| 品牌调性 | 推荐视觉风格(主) | 次选 |
|---|---|---|
| 高端 | 极简主义 / 现代主义 | 北欧风 / 玻璃拟物 |
| 亲和 | 北欧风 / 复古风 | 极繁主义(活泼向) |
| 科技 | 未来主义 / 终端风 | 现代主义 / 玻璃拟物 |
| 活力 | Y2K千禧 / 极繁主义 | 像素风 / 新野兽派 |
| 专业 | 现代主义 / 极简主义 | 北欧风 |

## 五、风格组合搭配规则
- **主风格+辅风格**:主体用主风格(定基调),局部用辅风格(增特色)。如"极简主体 + 玻璃拟物卡片"
- **按场景组合**:
  - 数据报告:终端风/未来主义(科技感)+ 现代主义(结构)
  - 品牌提案:极简/北欧(高端)+ 玻璃拟物(质感)
  - 创意campaign:极繁/Y2K(视觉冲击)+ 后现代(反叛)
  - 技术文档:终端风(极客)+ 现代主义(功能)
- **组合禁忌**:风格冲突不组合(如极简+极繁、终端+北欧),除非刻意后现代解构

## 六、动态能力矩阵(html/ppt 通用)

| 维度 | 能力 |
|---|---|
| 动态组件 | 卡片悬浮、按钮反馈、数据流动、打字机、粒子、光效、HUD面板、液态按钮、气泡卡片 |
| 动态交互 | 悬停(hover)、点击(click)、滚动(scroll)、加载(loading)、拖拽(drag)、键盘(keyboard) |
| 动态效果 | 过渡(transition)、动画(animation)、粒子(particles)、光效(glow)、3D变换、打字机、霓虹闪烁、液态流动 |
| 视觉审美 | 每风格的美学原则(理性/极简/粗犷/复古/通透/极客/柔和/反叛/科幻/乐观)驱动动效选择 |

---

## 七、实现工具(通用,不绑定具体产品)
- **html**:通用 HTML/CSS/JS(CSS Grid/Flexbox/animations/backdrop-filter 等原生能力)
- **ppt**:HTML PPT(html-ppt / frontend-slides 类通用skill生成,支持自定义主题)
- **字体**:系统字体栈 + 按风格选(衬线/无衬线/等宽/像素)
- **动效**:CSS animations/transitions + 按风格选动效类型(极简用淡入/终端用打字机/未来用霓虹/Y2K用液态)

---

## 八、输出交付SOP
1. 确定交付场景(文档/可视化/汇报)
2. 选格式(md/html/ppt)
3. 选品牌调性(高端/亲和/科技/活力/专业)
4. 选视觉风格(12种,按调性映射或按场景)
5. 套模板生成(格式模板 + 调性 + 风格)
6. 质量检验(结论先行 + MECE + 数据支撑 + 可执行 + So What)

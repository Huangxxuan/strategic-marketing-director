# 思维模型方法论驱动

> strategic-marketing-director v2.0.0 references
> 8思维模型从"孤立工具"升级为"决策驱动链":每模型驱动一决策环节,组合成双闭环方法论

## 思维决策方法论主链(收敛链)
```
5W2H(界定) -> MECE(拆解) -> 因果图(根因) -> 决策树(量化选择) -> 六帽(多维审视) -> 金字塔(结构表达) -> SCQA(叙事包装)
                                                              ↑
                                                         脑暴(发散补缺,界定前/决策后介入)
```

---

## 8模型逐一:使用场景 + 决策驱动 + SOP + 输出 + 闭环

### 1. 5W2H -- 问题界定驱动
- **使用场景**:接到模糊问题/需求的第一步,界定问题边界
- **决策驱动**:把模糊问题转为可分析的精确问题
- **SOP**:What(现象)-> Why(影响)-> Who(责任/受益)-> When(时机)-> Where(边界)-> How(方向)-> How much(约束)
- **输出**:问题定义卡(一句话精确问题 + 边界 + 目标)
- **闭环**:问题定义卡 -> 喂给 MECE 拆解

### 2. MECE -- 结构拆解驱动
- **使用场景**:复杂问题需拆解为可分析子问题
- **决策驱动**:把混沌问题分解为可逐项分析的子问题树
- **SOP**:选拆解维度 -> 第一层(3-5互斥子项)-> 逐层下拆(不超3层)-> 检验(独立+穷尽)
- **输出**:问题拆解树(叶节点可独立分析)
- **闭环**:叶节点 -> 因果图找根因 / 数据验证

### 3. 因果图(鱼骨图) -- 根因追溯驱动
- **使用场景**:问题现象已知,需找根本原因
- **决策驱动**:从现象追到可干预的根本原因,而非治标
- **SOP**:定义问题(鱼头)-> 选维度(6M:人/机/料/法/环/测 或 4P)-> 列原因(脑暴)-> 5Why深挖 -> 标记高杠杆根因
- **输出**:根因图(鱼骨 + 5Why根因链 + 高杠杆点)
- **闭环**:根因 -> 决策树/六帽评估方案

### 4. 决策树 -- 量化决策驱动
- **使用场景**:多方案选择,需量化比较
- **决策驱动**:把定性选择转为量化期望值比较
- **SOP**:列备选方案 -> 估计结果及概率 -> 估计价值 -> EV=Σ(概率×价值) -> 比较选优,标注高不确定节点
- **输出**:决策树图(方案-结果-概率-EV)+ 推荐方案
- **闭环**:推荐方案 -> 六帽审视风险

### 5. 六顶思考帽 -- 多维审视驱动
- **使用场景**:方案需多角度审视 / 团队决策有分歧
- **决策驱动**:避免单一视角盲区,六维全面评估
- **SOP**:白帽(事实)-> 红帽(情感)-> 黑帽(批判)-> 黄帽(乐观)-> 绿帽(创新)-> 蓝帽(管控总结)
- **输出**:六维审视报告(每帽结论 + 综合判断)
- **闭环**:审视优化方案 -> 金字塔表达

### 6. 金字塔原理 -- 结构化表达驱动
- **使用场景**:汇报方案/写报告/沟通结论
- **决策驱动**:结论先行、论据支撑,让受众快速抓核心
- **SOP**:顶层(核心结论一句话)-> 第二层(3支撑论据MECE)-> 第三层(事实/数据)-> 检验(纵向疑问回答/横向MECE)
- **输出**:金字塔结构(结论-论据-事实)
- **闭环**:金字塔 -> SCQA 包装叙事

### 7. SCQA -- 叙事框架驱动
- **使用场景**:方案需讲清背景与价值(开场/报告/提案)
- **决策驱动**:用情境-冲突-问题-答案吸引注意并引出方案
- **SOP**:S情境(共识背景)-> C冲突(打破情境)-> Q问题(聚焦)-> A答案(方案)
- **输出**:SCQA 开场叙事
- **闭环**:SCQA 开场 -> 金字塔展开方案

### 8. 脑暴 -- 发散补缺驱动
- **使用场景**:需突破常规/找新方案/补盲点(界定前/决策后)
- **决策驱动**:打破收敛思维,产出多元可能再收敛
- **SOP**:明确主题 -> 限时产出(不批评,量优先)-> 聚类分组 -> 评估筛选(可行性×影响)-> 收敛
- **输出**:方案池(聚类 + 筛选)
- **闭环**:方案池 -> MECE/决策树收敛

---

## 方法论驱动总结(双闭环)
- **收敛主链**:5W2H 界定 -> MECE 拆解 -> 因果图根因 -> 决策树量化 -> 六帽审视 -> 金字塔表达 -> SCQA 叙事
- **发散补链**:脑暴在界定前(发散问题域)和决策后(补缺方案)介入,打破收敛盲区

**决策方法论驱动 = 每个模型驱动一个决策环节,组合形成"界定-拆解-根因-选择-审视-表达"完整闭环。**

## 使用场景路由表

| 决策环节 | 驱动模型 | 触发问题 | 输出 |
|---|---|---|---|
| 界定问题 | 5W2H | "问题到底是什么" | 问题定义卡 |
| 拆解结构 | MECE | "由哪些子问题组成" | 拆解树 |
| 找根因 | 因果图 | "为什么会这样" | 根因图 |
| 选方案 | 决策树 | "A 还是 B" | 决策树+EV |
| 审视风险 | 六帽 | "方案有无盲区" | 六维审视报告 |
| 表达结论 | 金字塔 | "怎么讲清楚" | 金字塔结构 |
| 讲故事 | SCQA | "怎么开场吸引" | SCQA 叙事 |
| 找新思路 | 脑暴 | "还有什么可能" | 方案池 |

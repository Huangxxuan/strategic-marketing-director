# 增长执行SOP(5 Phase闭环)

> strategic-marketing-director v2.0.0 references
> 整合全能力链的可落地增长执行流程:假设驱动的实验闭环

## 增长执行本质
"假设驱动的实验闭环":定北极星 -> 诊断瓶颈 -> 设计假设 -> 实验验证 -> 规模化/废弃 -> 迭代。所有能力(模型/渠道/心理/数据/思维)都是闭环工具。

---

## 5 Phase增长执行SOP

### Phase 0:目标设定
- 北极星指标(唯一增长方向)
- AARRR 子指标拆解(获客/激活/留存/变现/推荐)
- OMTM(本季度一指标)

### Phase 1:增长诊断(5阶段:搜索+诊断)
- 搜索:行业/竞品/渠道增长数据(搜索能力)
- AARRR 漏斗诊断(瓶颈环节定位)
- 心理诊断:流失/不转化机制(深度心理三层穿透)
- 思维驱动:5W2H界定 + MECE拆解 + 因果图根因

### Phase 2:增长策略(5阶段:策略)
- 飞轮设计(增长引擎自循环)
- AARRR 聚焦环节(选最高杠杆环节)
- 渠道组合(POES选增长渠道,见 channels.md)
- 心理杠杆(打动机/损失厌恶/社交认同,见 psychology-deep.md)
- 增长假设设计(假设-验证-指标)

### Phase 3:执行落地(5阶段:执行)
- 增长实验SOP:假设 -> 实验设计 -> 上线 -> 数据 -> 复盘
- 渠道执行:按渠道SOP执行(社媒/裂变/KOL/私域,见 channels.md)
- 行为设计:BJFogg/Nudge 设计转化引导
- 团队对齐:OKR + RACI

### Phase 4:数据复盘(5阶段:复盘)
- AARRR 各环节指标复盘
- LTV-CAC 单位经济
- 实验结果(A/B测试显著性)
- 心理假设验证
- 飞轮效果评估

### Phase 5:迭代(PDCA闭环)
- 规模化(验证有效的放大)
- 废弃(无效的停止)
- 持续迭代(回到Phase 0校准北极星)

## 增长执行输出模板(5份标准化交付)

1. **增长目标卡**:北极星指标 + AARRR拆解 + OMTM + 量化目标
2. **增长诊断报告**:瓶颈环节 + 心理机制(三层穿透)+ 根因
3. **增长策略方案**:飞轮 + 聚焦环节 + 渠道组合 + 心理杠杆 + 增长假设
4. **增长实验清单**:假设 × 实验 × 指标 × 状态(进行中/有效/废弃)
5. **增长复盘报告**:指标达成 + 单位经济 + 实验结论 + 迭代决策

---

## 增长执行闭环
```
搜索(增长数据)-> 诊断(瓶颈+心理)-> 策略(飞轮+渠道+心理杠杆)-> 执行(实验+渠道SOP)-> 复盘(指标+单位经济)-> 迭代(PDCA)
```

**关键原则**:增长执行不是一次性方案,而是持续假设-验证-规模化的迭代过程。北极星定方向,飞轮搭引擎,AARRR拆漏斗,渠道+心理做杠杆,实验做验证,数据做复盘,PDCA做迭代。

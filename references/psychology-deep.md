## 一、v1.0.0 现状与不足

v1.0.0 心理库(BJFogg/COM-B/EAST/Nudge/KANO/CJM/70+速查)偏向"行为设计与助推速查",解决"如何引导行为"。不足:

## 二、深度心理洞察方法论体系(7层)

心理学在营销中的应用分7层,每层解决不同问题:

| 层 | 领域 | 核心问题 | 代表模型 |
|---|---|---|---|
| 1 认知层 | 认知心理 | 人如何感知/注意/记忆/决策 | 双系统理论、框架效应、锚定、注意力选择 |
| 2 动机层 | 动机心理 | 人为什么行动 | 马斯洛、赫茨伯格双因素、自我决定、期望理论 |
| 3 情感层 | 情感心理 | 情绪如何影响决策 | 情感启发式、品牌依恋 |
| 4 社会层 | 社会心理 | 社会如何影响个体 | 西奥迪尼六原则、从众、群体认同 |
| 5 行为经济层 | 行为经济 | 决策偏误与助推 | 损失厌恶、禀赋效应、心理账户、现状偏见 |
| 6 消费决策层 | 消费心理 | 购买如何发生 | 决策5步、ELM、涉入度 |
| 7 品牌心理层 | 品牌心理 | 品牌如何在心理扎根 | 品牌联想、品牌认同、品牌原型、品牌忠诚 |

---

## 三、深度心理模型库(7层详解)

### 1. 认知层(人如何处理信息)
- **双系统理论(卡尼曼)**:系统1快思考(直觉/自动)/系统2慢思考(理性/费力)。营销多触系统1(直觉决策)
- **框架效应**:同一信息不同表述影响决策("95%无脂肪"vs"5%脂肪")
- **锚定效应**:先入信息影响判断(原价划掉显示折扣)
- **选择性注意**:人只注意与自己相关的(鸡尾酒会效应)
- **首因/近因效应**:首尾信息记忆最深

### 2. 动机层(人为什么行动)
- **马斯洛需求层次**:生理->安全->社交->尊重->自我实现。定位需求层级
- **赫茨伯格双因素**:保健因素(防不满)/激励因素(促满意)。营销区分防痛/促愉
- **自我决定理论(SDT)**:自主/胜任/关系三大内驱力。驱动内在动机
- **期望理论**:动机=期望×工具性×效价。判断行为驱动力

### 3. 情感层(情绪与决策)
- **情感启发式**:人用情感好恶做决策(我喜欢->选它)
- **品牌依恋理论**:品牌满足自主/胜任/关系需求,形成情感依恋
- **情感诉求**:恐惧(风险规避)/喜悦(收益)/信任(安全)的传播应用

### 4. 社会层(社会影响)
- **西奥迪尼六原则**:互惠/承诺一致/社会认同/权威/喜好/稀缺。说服六大武器
- **从众与社会认同**:人参考他人行为(销量展示/评价/UGC)
- **群体认同**:人通过品牌表达群体归属(身份消费)
- **社会比较**:人通过比较定位自己(参照群体)

### 5. 行为经济层(决策偏误)
- **损失厌恶**:损失痛苦>获得快乐(损失框架更有效)
- **禀赋效应**:拥有后高估价值(试用/拥有感)
- **心理账户**:人按心理类别管理金钱(不同账户不同敏感度)
- **现状偏见**:倾向维持现状(默认选项力量)
- **沉没成本**:已投入影响继续决策(会员/积分锁存)

### 6. 消费决策层(购买过程)
- **购买决策5步**:问题认知->信息搜索->方案评估->购买决策->购后行为
- **精细可能性模型(ELM)**:中枢路径(理性深度处理)/边缘路径(线索启发)。高涉入走中枢,低涉入走边缘
- **涉入度模型**:高涉入(高价/风险)->深度决策;低涉入(低价/日常)->习惯/启发

### 7. 品牌心理层(品牌心智)
- **品牌联想(Aaker)**:品牌在心智的联想网络(属性/利益/态度)
- **品牌认同**:品牌匹配自我概念/理想自我(我=用这个品牌的人)
- **品牌原型(12原型)**:品牌人格化(创造者/探索者/英雄/叛逆者等),情感共鸣
- **品牌信任/忠诚**:信任(可靠/意图)->态度忠诚->行为忠诚

## 四、心理洞察SOP(从现象到策略)

```
1. 现象观察:用户行为/反馈/数据现象(如:加购不付款/复购高/流失)
2. 三层穿透:行为(做什么)-> 情感(感受什么)-> 动机/认知(为什么)
3. 模型匹配:用7层模型对应解释心理机制
4. 洞察提炼:一句话揭示"未被满足的深层需求/未说出口的心理"
5. 策略转化:洞察 -> 产品/营销/传播策略(打哪个心理痛点)
6. 行为设计:BJFogg/Nudge 设计行为引导(如何助推)
7. 验证:A/B测试/用户反馈 验证心理假设
```

## 五、三层穿透思维逻辑(底层)

心理洞察的底层逻辑:**行为 -> 情感 -> 动机/认知** 三层穿透。

- **表层(行为)**:用户做什么(可观测)
- **中层(情感)**:用户感受什么(需洞察)
- **深层(动机/认知)**:用户为什么这么想/这么做(心理机制)

**洞察≠描述现象**。洞察是揭示"未被满足的深层需求/未说出口的心理"。

**示例**:
- 现象:"用户加购后不付款"
- 情感:"付款时有损失感/犹豫"
- 洞察:"用户有购买意愿但临门一脚被损失厌恶阻断,缺决策安全感"
- 策略:"提供风险逆转(无忧退换/试用)+社会认同(已购评价)降低决策风险"

## 六、心理洞察在营销全链的应用(15应用点闭环)

心理洞察贯穿营销全链,覆盖15个具体应用点,形成"发现 -> 洞察 -> 创作 -> 执行 -> 验证"闭环:

### 闭环链路
```
发现层(SEO关键词 / 搜索动机 / 内容机会 / 消费场景)
       ↓
洞察层(消费者洞察 / 用户心智 / 人群洞察 / 买点洞察 / 深层情绪)
       ↓
创作层(内容营销 / 文案撰写 / 情感共鸣 / 产品卖点翻译 / 具体画面)
       ↓
执行层(营销campaign)
       ↓
验证层(数据验证心理假设,回流发现层迭代)
```

### 15应用点:心理模型支撑 + 如何用

#### 发现层(4点)
1. **SEO关键词**:搜索意图=心理需求。用搜索意图模型+动机层,挖掘用户搜索背后的心理需求(解决问题/比较/逃避),关键词映射心理需求层级
2. **搜索动机**:搜索背后的心理驱动(信息性/导航性/交易性搜索)。用动机层(期望理论),搜索动机=期望×效价
3. **内容机会**:心理需求缺口(未被满足)。用马斯洛定位未满足需求层级,缺口=机会
4. **消费场景**:场景触发行为。用BJFogg(B=MAT),场景=Trigger+Ability+Motivation,识别高触发场景

#### 洞察层(5点)
5. **消费者洞察**:三层穿透(行为->情感->动机)。用7层模型综合,揭示未说出口的需求
6. **用户心智分析**:品牌在心智的位置。用品牌心理层(品牌联想/认同/原型)+认知层(记忆/感知),分析心智占位
7. **人群洞察**:群体心理画像。用社会层(群体认同)+动机层(价值观),洞察群体身份与需求
8. **买点洞察**:用户为什么买的心理理由(买点vs卖点)。用消费决策层(决策5步)+损失厌恶,买点=心理利益>心理成本
9. **深层情绪**:表层情绪下的深层情绪。用情感层(情感启发式),穿透表层(不满)到深层(恐惧/渴望)

#### 创作层(5点)
10. **内容营销**:内容满足心理需求。用动机层+情感层+社会层,内容=心理需求解决方案
11. **文案撰写**:心理钩子+说服。用西奥迪尼六原则+损失厌恶+框架效应,文案=心理触发器
12. **情感共鸣**:共享情感体验。用品牌依恋+群体认同,共鸣=触发共享情感记忆
13. **产品卖点翻译**:属性->利益->价值。用Means-end链(补充模型),把产品特征翻译为用户心理价值
14. **具体画面**:具象化触发心理。用具象效应(补充模型)+情感层,画面比抽象更触动系统1

#### 执行层(1点)
15. **营销campaign**:整合心理杠杆的多触点战役。综合(西奥迪尼+情感+社会+行为经济+品牌原型),campaign=心理杠杆矩阵

### 闭环性
发现层(找心理需求)-> 洞察层(理解心理机制)-> 创作层(转化为内容)-> 执行层(campaign放大)-> 验证层(数据验证)-> 回流发现层(迭代)。心理洞察贯穿全链,形成闭环。

### 需补充的模型(7层之外)
- **Means-end链**(产品卖点翻译):属性(产品特征)-> 利益(功能利益)-> 价值(心理价值)。把卖点翻译为用户心理价值
- **具象效应**(具体画面):具象信息比抽象信息更易触动系统1(情感启动)。画面/故事比数据更打动人

## 七、核心能力价值

1. **从"描述行为"到"理解机制"**:不只看用户做什么,理解为什么
2. **从"经验判断"到"模型驱动"**:心理模型支撑洞察,非拍脑袋
3. **洞察可转化**:洞察直接转产品/营销/传播策略
4. **行为可设计**:BJFogg/Nudge 落地转化引导
5. **假设可验证**:A/B测试闭环验证心理假设

## 八、与 v1.0.0 心理库的关系

- **v1.0.0 心理库**(BJFogg/COM-B/EAST/Nudge/KANO/CJM/70+速查):偏行为设计+速查,解决"如何引导行为"
- **v2.0.0 深度心理(本文件)**:补7层深度模型+洞察SOP+三层穿透,解决"为什么+如何洞察"
- **协同**:v1.0.0 是"行为设计工具箱"(执行层),v2.0.0 是"心理洞察引擎"(诊断/策略层)。先用深度心理洞察理解为什么,再用 v1.0.0 行为设计引导怎么做。

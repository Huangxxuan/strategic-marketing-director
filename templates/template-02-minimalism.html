02-03 / 分析过程

STP 定位 + 4P 组合

框架3 · STP(市场细分->目标->定位)

STP 定位

细分:敏感肌修护/抗老/美白/防晒四型。聚焦 P0 修护型(18-35 女)+ P1 抗老型(28-40 女)。定位"皮肤学级敏感肌功效护肤,云南植物成分+临床验证"。

框架3 · 4P(产品/价格/渠道/促销)

4P 组合

产品:爆款+抗老新品+礼盒三矩阵。价格:正价锚定+赠品替代折扣+会员专享。渠道:天猫+抖音双主场。促销:内容种草+专业背书+礼盒,非纯折扣。

04-05 / 分析过程

POES 渠道 + 增长路径

框架6 · POES 12 渠道

渠道组合

P 付费(信息流 30%+SEM 10%+KOL 20%)+ O 自有(私域 15%+小程序 5%)+ E 赢得(PR 5%+UGC 2%)+ S 共享(社媒 10%)。协同:Paid 引流 -> Owned 承接 -> Earned 放大 -> Shared 裂变。

框架4 · AARRR + 飞轮

增长路径

北极星=有效护肤方案交付数。AARRR:蓄水->预售->爆发->复购->裂变。飞轮:内容种草 -> AIPL 蓄水 -> 大促转化 -> 私域沉淀 -> 复购提升 -> 数据反哺。

07 / 风险与预案

风险预案

风险:竞品低价冲击
预案:坚守正价锚定,赠品+专业背书强化价值感,不打价格战
风险:流量成本上涨
预案:私域承接比例提至 30%,内容种草降获客成本
风险:新品动销不及预期
预案:预售测款,A/B 验证卖点,滞销转赠品组合

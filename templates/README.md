## 二、统一占位符规范（所有模板复用）

每套模板共享同一套占位符，用户全局替换 `{{KEY}}` 即可生成方案。

### 核心字段（必填）

| 占位符 | 说明 | 示例值 |
|---|---|---|
| `{{TITLE}}` | 品牌 / 项目名 | 薇诺娜 |
| `{{SUBTITLE}}` | 方案主旨一句话 | 以敏感肌专研心智壁垒为防御轴… |
| `{{SCENARIO}}` | 方案场景 | Q4 大促 GTM 方案 |
| `{{CONCLUSION}}` | 核心结论（一句话） | 以"敏感肌专研"… |
| `{{FRAMEWORKS}}` | 调用框架标注 | 框架3 营销组合 + 框架4 增长 + 框架6 传播 |

### 复盘指标（4 组，数值 + 名称）

| 占位符 | 说明 |
|---|---|
| `{{METRIC_1_NUM}}` / `{{METRIC_1_LABEL}}` | 指标1 数值 / 名称 |
| `{{METRIC_2_NUM}}` / `{{METRIC_2_LABEL}}` | 指标2 数值 / 名称 |
| `{{METRIC_3_NUM}}` / `{{METRIC_3_LABEL}}` | 指标3 数值 / 名称 |
| `{{METRIC_4_NUM}}` / `{{METRIC_4_LABEL}}` | 指标4 数值 / 名称 |

### 可变区域（HTML 注释标记）

搜索 `SECTION: ` 定位可替换段落，替换整段为你的内容：

| 标记 | 区域 |
|---|---|
| `SECTION: STP` | STP 定位分析 |
| `SECTION: 4P` | 4P 组合分析 |
| `SECTION: POES` | POES 渠道组合 |
| `SECTION: GROWTH` | 增长路径 |
| `SECTION: ACTIONS` | 行动建议表格行 |
| `SECTION: RISKS` | 风险预案条目 |

## 三、统一结构规范

8 slides 固定结构（所有模板一致，仅视觉呈现不同）：

1. **封面** — 标题 + 场景 + 主旨
2. **目录** — 方案结构
3. **核心结论** — 一句话结论 + 调用框架
4. **STP + 4P 分析** — 定位 + 营销组合
5. **POES 渠道 + 增长路径** — 渠道组合 + AARRR/飞轮
6. **行动建议** — P0/P1 优先级表格
7. **风险预案** — 风险 + 预案两栏
8. **复盘指标** — 4 个 metric 卡片

## 四、统一技术规范

| 维度 | 要求 |
|---|---|
| 依赖 | 零依赖，原生 HTML/CSS/JS，不引外部 CDN/字体/库 |
| 分发 | 单文件，一个 .html 即可分发 |
| 响应式 | 768px 断点适配移动端 |
| 打印 | `@media print`，每 slide 一页，支持 Ctrl+P 导出 PDF |
| 无障碍 | `aria-label` / `focus-visible` / 语义化标签 / 键盘操作 |
| 交互 | `←` `→` 翻页、空格下页、`Home/End` 首尾、`P` 打印 |
| 动态计算 | 进度条 / 页码由 JS 动态计算，支持任意 slide 数，不硬编码 |
| 协议 | MIT |

## 五、使用说明（用户）

1. **选模板**：按调性-风格映射（见第七节）选合适风格
2. **本地预览**：`python3 -m http.server 8899`，浏览器打开模板文件
3. **替换占位符**：全局替换 `{{KEY}}`（核心字段）+ 搜索 `SECTION:` 替换可变区域
4. **导出**：浏览器 `Ctrl+P` 打印为 PDF

## 六、开发规范（5 模板已完成）

新增模板时遵循：

1. 以 `template-01-modernism.html` 为基线，复制重命名为 `template-XX-style.html`
2. 按对应风格（`output-templates.md` 第三节）重设计设计 token（色/字/间距/圆角/阴影）+ 组件 + 动效
3. **占位符命名与结构保持不变**（第二节规范），仅改视觉呈现
4. 头部注释含：风格说明 + 占位符清单 + 可变区域索引 + 结构 + MIT
5. 验证清单：零依赖 / 响应式 / 打印 / 无障碍 / `curl` 返回 200
6. 按需调用 `ui-design-workflow`（阶段2 设计系统 + 阶段3 审美方向 + 阶段4 构建 + 阶段6 审查）
7. 反 AI 模板审查通过（Anti-Slop + Pre-Flight Check）后方可标记 ✅
